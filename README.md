# Angel.Team — Школа фигурного катания

Современный интерактивный сайт школы фигурного катания **Angel.Team**, построенный на **Vite + React + TypeScript + Tailwind CSS + Framer Motion**.

## Ключевые визуальные и интерактивные механики

1. **Hero с 3D-орбитой карточек элементов** (`HeroOrbitSection.tsx`):
   - 8 карточек направлений и элементов (Лутц, Аксель, Скольжение, Вращения, Хореография, Программы, ОФП, Сборы) вращаются по суперэллипсу на пружинной физике (`requestAnimationFrame` с 4 подшагами на кадр).
   - Поддержка перетаскивания и «броска» карточек с возвратом на пружине, фильтрация по категориям, переключение режимов **Орбита / Сетка** и фокус-просмотр по клику.
2. **Кобальтовый горизонт и двойная скролл-лента** (`HorizonGlow.tsx`, `MarqueeSection.tsx`):
   - Плавный световой переход при прокрутке и две встречные полосы дисциплин, привязанные к скроллу.
3. **Философия и закреплённая статистика** (`AboutStatsSection.tsx`):
   - Пословное проявление текста при скролле (`AnimatedText`), закреплённая левая колонка и 5 анимированных счётчиков с вырисовывающимися разделительными линиями.
4. **Направления с эффектом наслаивающихся карточек** (`ProgramsStackSection.tsx`):
   - Карточки программ фиксируются и плавно масштабируются при прокрутке (`useScroll` + `useTransform`).
5. **Тренерский состав с интерактивной волной** (`CoachesWaveSection.tsx`):
   - Ряд карточек плавно приподнимается волной за курсором с переключением подробной карточки тренера.
6. **Расписание с фильтром по аренам, тарифы и модальное окно записи** (`SchedulePricingSection.tsx`, `BookingModal.tsx`).

## Запуск проекта

```bash
npm install
npm run dev
```

Для продакшен-сборки:

```bash
npm run build
```
